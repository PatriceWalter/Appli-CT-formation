VERSION GITHUB SANS DOSSIER ASSETS

Tous les fichiers doivent être envoyés AU MÊME ENDROIT dans le dépôt GitHub.

À la racine du dépôt vous devez voir :
- index.html
- illustration_01.webp
- illustration_02.webp
- ...
- illustration_13.webp

IMPORTANT :
1. Ne créez PAS de dossier assets.
2. Ne renommez PAS les illustrations.
3. Dans GitHub : Add file > Upload files.
4. Sélectionnez TOUS les fichiers décompressés en une seule fois.
5. Cliquez sur Commit changes.
6. Rechargez ensuite GitHub Pages avec Ctrl+F5.

Cette version évite les problèmes de chemin relatifs vers /assets.
