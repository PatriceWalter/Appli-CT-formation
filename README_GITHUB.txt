VERSION GITHUB ALLÉGÉE

Cette version a été optimisée pour éviter les plantages du navigateur pendant l'envoi sur GitHub.

CONTENU
- index.html
- dossier assets avec les illustrations en WebP

MISE EN LIGNE
1. Décompressez ce ZIP sur votre PC.
2. Ouvrez votre dépôt GitHub.
3. Cliquez sur Add file > Upload files.
4. Glissez index.html puis le dossier assets complet.
5. Validez avec Commit changes.

IMPORTANT
Ne mettez pas le fichier ZIP directement dans GitHub Pages : il faut envoyer les fichiers décompressés.
Le dossier assets doit rester à côté de index.html.
