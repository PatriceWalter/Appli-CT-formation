V8.8 - GITHUB ROBUSTE

Cette version est prévue si vous envoyez les illustrations une par une sur GitHub.

EMPLACEMENT RECOMMANDÉ
- index.html à la racine
- dossier assets à la racine
- toutes les illustrations dans assets

La version V8.8 essaie automatiquement :
1. assets/nom_image.webp
2. nom_image.webp à la racine
3. les anciens noms illustration_XX.webp lorsque disponibles

Donc même si certaines images ont été envoyées à la racine au lieu du dossier assets, elles peuvent encore s'afficher.

ATTENTION
- Ne renommez pas les fichiers descriptifs fournis.
- GitHub est sensible aux majuscules/minuscules.
- Après remplacement de index.html, attendre le déploiement GitHub Pages puis faire Ctrl+F5.
